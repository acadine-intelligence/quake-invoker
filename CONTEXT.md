# Domain glossary

| Term | Meaning |
|------|---------|
| Orb | One of Quas (Q), Wex (W), or Exort (E). |
| Orb sequence | The three held orbs in the order they were selected, oldest first. |
| Recipe | An exact orb sequence that identifies an invocation. Different orders can identify different invocations. |
| Invocation | The result of a recipe. It can be a spell, a Quake weapon, or another ability. |
| Invoke | Prepare the result of the current recipe in an invoked slot. |
| Invoked slot | One of the two places that hold prepared invocations for use. These are separate from the slots that hold orbs. |
| Cast | Activate a prepared invocation. For a Quake weapon, this fires the weapon. |
| Mana | A combat resource that spells can spend and EMP can remove. It is separate from weapon ammunition. |
| Portal pair | Two linked openings. Traversal enters one opening and exits the other. |
